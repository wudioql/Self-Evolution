## 1. MFC 原理与漂移

**一台 MFC 只用一种测量原理，热式与压差式互斥，不会同时存在。**

| 原理 | 怎么测 | 优势 | 局限 |
|---|---|---|---|
| 热式 | 测气体流过加热传感器时的温度差 | 低压损、小流量精度高 | 受气体比热容影响大，换气体要换标定 |
| 压差式 | 测气体流经节流件前后的压降（层流） | 响应极快、耐高压 | 需要较高入口压力 |

- **选型**：CVD / 扩散的常规工艺用热式（主流）；快速脉冲、高压注入用压差式。
- **标定**：通常用 N₂ 标准气标定；实际用其他气体时乘对应的转换系数（Gas Conversion Factor）。
- **两种漂移**：温漂（环境温度变化引起传感器电阻变化）；零点漂移（长期使用后零点偏移）。都靠定期校准处理，不能靠调工艺参数绕过去。
- **确认型号**：看 MFC 铭牌上的 Model Number 或标注（Thermal / Laminar），换备件时不能混用。

## 2. 特气特性与应急

| 气体 | 特性 | 应急要点 |
|---|---|---|
| SiH₄（硅烷） | 自燃，泄漏遇空气即爆 | 立即切断气源、启动喷淋、人员撤离 |
| NH₃（氨） | 剧毒、强腐蚀，刺激呼吸道和眼睛 | 佩戴防毒面具，酸性水幕吸收中和 |
| N₂O | 助燃（本身不自燃，但强烈支持燃烧） | 切断气源，用合适灭火剂 |
| TEOS | 液态源、易燃，遇水水解产生颗粒堵管路 | 严格控温，防止水汽进入 |
| O₃ | 强氧化剂、有毒，通常在线生成 | 尾气必须经高温破坏处理 |
| PH₃ / AsH₃ / B₂H₆ | 掺杂气体，剧毒，微量可致命 | 双层管路（Double Containment）+ 高灵敏 GDS |

**两种 CVD 常用化学品**：

- **NF₃**：腔室原位清洗（In-situ Clean），靠 RF 等离子体激发 F* 自由基与 Si / SiO₂ 反应生成挥发性 SiF₄。强氧化剂，与有机物或油脂接触可能爆炸；**GWP（IPCC AR5 口径）16,100 倍 CO₂**（AR4 口径为 10,800）。输送要用耐腐蚀 MFC（Ni 合金密封），禁用普通橡胶密封件。泄漏时 GDS 报警**不要盲目进入**——NF₃ 本身毒性中等，但燃烧产物 HF 剧毒且强腐蚀，需 SCBA 并用石灰水中和。
- **TEB（硼源，P 型）/ TEPO（磷源，N 型）**：TEOS 的衍生物，液态源。极易吸收空气中水分水解，生成硼酸 / 磷酸颗粒，堵塞 MFC 和 showerhead。输送用鼓泡器（Bubbler）或 VCM（流量控制汽化器），**源瓶温度按前驱体饱和蒸气压设定，控温精度通常 ±0.1℃**（设定值随前驱体和厂商而定，以源瓶 datasheet 为准）；换瓶动作要快，缩短管路暴露在大气中的时间。

**阀件失效模式**（三类阀的共性问题）：密封件老化 → 内漏 / 外漏；阀芯卡死 → 无法动作；驱动机构故障。

## 3. 尾气处理三法

| 方法 | 原理 | 主要对付 |
|---|---|---|
| **Scrubber**（洗涤塔） | 化学药液喷淋吸收 | 酸性 / 碱性尾气：HF、Cl₂、未反应的 NF₃ 及其副产物 |
| **Burn Box**（燃烧箱） | 高温燃烧氧化分解 | 易燃 / 有毒气体：SiH₄、NH₃ → SiO₂、H₂O、N₂ |
| **Cold Trap**（冷阱） | 极低温（液氮）冷凝捕集 | 高沸点副产物，防止堵塞排气管或损坏真空泵 |

- **维护三件事**：定期换洗涤液、清理燃烧室积灰、排空冷阱冷凝物；同时监控压差，压差升高往往就是管路开始堵。
- **臭氧的尾气**：热氧化（TOX / Burn Box）在 600–800℃ 下 2O₃ → 3O₂；若混有 VOCs，高温会将其彻底氧化为 CO₂ 和 H₂O。机台端（Point-of-Use）也常用催化分解，温度更低但能耗更省。排气管材质要耐氧化（如 316L 不锈钢或特殊涂层）。

## 4. 控压：一句话总结的展开

- **核心公式**：进气流量（Inflow）= 抽气速率（Pumping Speed）。调 APC 阀开度或 MFC 流量，维持腔压恒定。
- **角色分工**：APC 阀是「手」（改变开度 → 改变流导 → 改变抽气阻力），真空规是「眼」。**电容薄膜规**给绝对压力、不受气体种类影响，是控压回路的主反馈源；**皮拉尼规**只作低真空段辅助，读数需按气体热导率补偿。
- **执行机构选蝶阀的原因**：流导与阀板角度的线性度好，便于 PID 控制；配伺服电机响应快，能跟上 MFC 突然加流量；结构简单、耐颗粒，不易卡死。
- **失控后果**：APC 阀卡死或规管漂移 → 膜厚不均、CD 偏移，严重时触发特气反应异常。
- **两条安全联动**：
  - **防倒吸（Anti-Suckback）**：腔压异常低于大气压或泵停机时，迅速关闭进气阀并充 N₂，防止大气倒灌污染管路或引发 SiH₄ 回火。
  - **泄漏率监测（Leak Rate）**：关阀后测压力上升率（mTorr/min），判断密封性；对 AsH₃ 这类剧毒气体，微漏也不可接受。

## 怎么用它

- 流量偏差：先按 1 确认原理与标定系数，再区分温漂还是零点漂移，最后才怀疑硬件。
- 特气报警：按 2 的表直接执行对应动作，不凭记忆临时判断；NF₃ 情形尤其不要盲进。
- 尾气异常（压差升高、泵异响）：按 3 的三法定位是哪一环，再查维护项。
- 控压波动：按 4 的顺序查「眼（规）→ 脑（APC / PID）→ 手（蝶阀）」，与 `FM-0013` 的实际排查路径对照。
