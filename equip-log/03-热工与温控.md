## 笔记原文

### ① 加热元件

- **电阻丝**：传统炉管，成本低升温慢，易氧化断裂、局部过热变形。
- **卤素灯**：RTP / RTA 设备，响应速度快，可能灯丝烧断、石英管污染、光衰。
- **红外加热**：非接触式，均匀性高，需注意反射率变化导致的温控偏差。

### ② 控制大脑：PID 整定

> 本节统一用**时间型 + 增益型**记法：`Kp` = 比例增益（越大越强），`Ti` = 积分时间（**越长，积分作用越弱**）。
> 若机台界面用的是另一种记法（`Ki` 增益、`PB` 比例带），方向会反过来，判别方法见「盲区 / 待核对」。

- **P（比例 proportional）**：决定响应速度。`Kp` 过大 → 超调（Overshoot）或震荡（Oscillation）；`Kp` 过小 → 响应迟钝，并留下稳态误差。
- **I（积分 integral）**：靠累积偏差消除稳态误差。**`Ti` 越短，积分作用越强**：`Ti` 太短会超调和低频震荡，`Ti` 太长则稳态误差收敛得慢。
- **D（微分 derivative）**：按偏差变化趋势提前动作，抑制超调、增加稳定性。D 过大对噪声敏感，过小抑制不住惯性。

参数调节（按 `Kp` / `Ti` 统一整理）：

| 现象 | 原因 | 调整 | 实际在做什么 |
|---|---|---|---|
| 超调 | `Kp` 过大 / `Ti` 过短 | 减小 `Kp`、增大 `Ti`、增大 D | 减弱比例、减弱积分、增强微分 |
| 震荡 | `Kp` 过大 / `Ti` 过短；或 D 过大（噪声） | 减小 `Kp`、增大 `Ti`、减小 D | 减弱比例与积分；D 只在振荡由噪声引起时才减 |
| 稳态误差 | `Ti` 过长（积分作用太弱） | 减小 `Ti` | 缩短积分时间，增强积分作用 |
| 响应太慢 | `Kp` 太小 / `Ti` 过长 | 增大 `Kp`、减小 `Ti` | 增强比例，缩短积分时间 |

> ⚠️ 比例也有两种记法：`Kp`（比例增益，越大越强）与**比例带 `PB`**（% 或 ℃，**越大越弱**）。上表按 `Kp` 写；若界面显示的是比例带，超调时应**增大 PB**。判别同样只看标签和单位，不看字母。

### ③ 感知神经：热电偶与塞贝克效应

| 型号 | 材质 | 大致量程 | 特性 |
|---|---|---|---|
| K | 镍铬 / 镍硅 | -200~1200℃ | 最常用，性价比高，线性度好，适用一般氧化性气氛 |
| E | 镍铬 / 康铜 | -200~900℃ | 热电动势最大，灵敏度最高，适合低温精密测量 |
| J | 铁 / 康铜 | -40~750℃ | 便宜，正极易生锈，不适合氧化性气氛，常用还原性气氛 |
| S | 铂铑 10 / 铂 | 0~1600℃ | 稳定性极好，精度好，适合高温氧化气氛，SiC 高温退火常用 |
| R | 铂铑 13 / 铂 | 0~1600℃ | 与 S 型类似，热电动势稍大，灵敏度略高，同样适用于高温退火 |
| B | 铂铑 30 / 铂铑 6 | 200~1700℃ | 超高温专用，室温下热电动势极小，无需冷端补偿，极稳定，适合极高温度退火 |

- **SiC 等超高温工艺必须选 S / R / B 型（贵金属）**：普通金属热电偶在极高温会迅速氧化或发生晶格变化，导致漂移甚至熔断。
- **冷端补偿**：必须精确补偿环境温度对参考端的影响。
- **补偿导线**：必须使用与热电偶分度号匹配的专用补偿导线，否则引入巨大误差。

### 总结

- **工艺灵魂**：热场均匀性与 Thermal Budget（准 + 匀）。
- **Profile（温度曲线）**：整个工艺中温度随时间变化的完整轨迹。
- **Ramp（升 / 降温速率）**：控制升温速率，防止热应力破裂。
- **Soak（保温）**：目标温度保持，确保晶圆温度均一化。
- **TUS（Temperature Uniformity Study）**：用 profile TC mapping 炉温，确保片内 / 键温差在规格内。
- **Thermal Budget（热预算）**：时间与温度的等效积分。高温短时间（RTA）与低温长时间可能达到相似的掺杂剂效果，但扩散程度不同。

## 盲区 / 待核对

- ✅ PID 符号已统一（2026-11-01）：② 的正文与表格一律按 `Kp` + `Ti` 写。
  机台界面常见变体：`Ti` / Integral time（时间单位）→ 越大积分越弱；`Ki` / I gain / `%/s` / `1/s` → 越大积分越强；`repeats per minute` / `Reset` → 越大越强（即 1/Ti）；`PB` 比例带（%）→ 越大比例越弱。
- 待补：实际在用的机台是哪一型热电偶、补偿导线型号——补在「元信息」的挂靠场景里。

## 怎么用它

- 调机或复机前：先确认界面记法是 `Kp`/`Ti` 还是 `Ki`/`PB`，再照 ② 的表找方向。
- 换热电偶 / 换补偿导线：直接查 ③ 的量程与匹配要求，S / R / B 型的高温理由就是那一行。
- 评审 recipe profile：用「总结」里的 Ramp / Soak / TUS / Thermal Budget 四个词描述问题，不另造说法。
