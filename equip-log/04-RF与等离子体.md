## 笔记原文

> 以下三则与那句总结为本人当天原话，未改写。

1.matcher（阻抗变换网络）最典型为L型（也有π型、T型三电容机台），tune串联可变电容，用于调谐，主要处理电抗、load并联可变电容，用于负载匹配，主要处理电阻变换。两个自由度正好对应复阻抗的实部和虚部，把腔体阻抗变换回50Ω。传输线：50Ω同轴，从电源经matcher到腔体，matcher需尽量靠近腔体。

2.双频PECVD通常为13.56MHz（HF，工业ISM频段，PECVD标准高频）+380/400kHz（LF）。HF控等离子体密度和沉积速率，LF控离子轰击能量，从而影响膜应力与致密度。RF参数：设定功率（setpoint）、入射（forward）、反射（reflected）。腔体实际吸收≈入射−反射。

3.阻抗匹配：RF电源和同轴线都按50Ω设计：只有接50Ω纯阻性负载，电源才能输出额定功率，功率计读数才代表真实输出，但等离子体腔与50Ω负载相差很大。CCP结构：等效电阻很低，只有几Ω到几十Ω，强容性（鞘层电容），电抗可达几十到几百欧。反射功率反映腔体阻抗偏离50Ω的程度。失配的代价，用反射系数表示：Γ=(ZL−50)/(ZL+50)，反射功率=入射功率×|Γ|²；腔体实际吸收=入射×(1−|Γ|²)。

一句话：排查方向：反射高时，先分清是腔体侧（沉积物、压力、气体）还是传输侧（线缆、接头、接地）造成的，再进入matcher或低频模块。

## 当天展开（本人笔记未覆盖的部分）

### ① RF 系统：电源与传输线

- **电源（generator）**：除功率外还能设反射保护阈值、起辉功率 ramp、部分机型支持小范围频率微调辅助匹配。电源出口自带方向耦合器，**它显示的 forward / reflected 是电源端的值**。
- **传输线**：50Ω 同轴，电源 → matcher → 腔体；matcher 越靠近腔体越好（无匹配段的驻波与损耗）。
- **实际失效点**：接头打火/氧化/未拧紧、屏蔽层破损、弯折半径过小、线缆过长。
- **接地也是 RF 回路的一半**：接地带氧化或接地电阻变大，表现与「匹配不良」几乎一样。
- 读数要分清三个位置：**setpoint / 电源端 forward / 电源端 reflected**，与腔体端差一个线损，两个位置的数不能直接比。
- 长期漂移来源：功率计未校准、耦合器老化 —— 做趋势监控前先确认读数本身可靠。

### ② 等离子体基础

- **是什么**：部分电离气体，电子密度 ≈ 离子密度（准中性）；电子温度几 eV（上万 K），离子接近室温；电离率常在 10⁻⁴ 量级，活性主要来自电子、离子与**自由基**。
- **鞘层**：电子先流失，电极前形成正离子占优的薄层；腔内电压主要降在鞘层上，离子在此被加速打向电极/晶圆。鞘层也是腔体呈容性的根源（回到笔记 3）。
- **击穿到辉光**：Townsend 电子雪崩 → 击穿 → 辉光放电；二次电子发射系数（γ）越低，击穿电压越高，**电极表面污染会改变起辉行为**。
- **放电模式**：CCP（本机台）低功率为 **α 模式**（鞘层加热），功率升高进入 **γ 模式**（二次电子参与）；模式切换时阻抗与发光突变，是起辉不稳、反射跳变的一种物理解释。**E / H 模式是 ICP 的叫法，不要套到 CCP 上。**
- **自偏压**：电极面积不对称 → 两侧鞘层压降不等 → 出现直流偏压，决定离子轰击能量，影响膜应力、致密度、台阶覆盖。
- **PECVD 特有**：SiH₄ / NH₃ / N₂O / TEOS 先被电子碰撞解离成自由基才成膜，所以改功率、改压力是先改自由基分布，再改折射率/应力/均匀性。

### ③ 诊断：OES 能告诉你什么

- 原理：发光 = 激发态原子/分子的特征辐射，谱线强度随该物种密度变化。
- 能做：是否起辉、起辉是否稳定、气体切换/配比是否到位、腔体洁净度、有无漏气、部分工艺终点。
- 不能做：直接测膜厚与均匀性（那是量测的事）。
- 前提是**有 baseline**：先存正常 recipe 的谱线形状，异常时对比；没有 baseline 的 OES 只能看热闹。

## 挂靠：颗粒（particle）与 MON PA NG

已记故障里有两条 MON PA NG（颗粒监控不合格）与一条膜厚均匀性异常，本节把机理挂上去，便于下次直接查。

**气相成核路径**（PECVD 典型）：

1. 电负性气体（硅烷类）中电子附着 → 形成负离子团簇；
2. 负离子被鞘层电场排斥，滞留在等离子体主体，停留时间长 → 长成纳米颗粒；
3. 颗粒靠重力、离子拖曳、热泳输运到晶圆表面 → 落尘。

**放大颗粒的工艺与设备因素**：

| 因素 | 表现 |
|---|---|
| 压力偏高 / 流量偏低 | 气体滞留时间变长，成核窗口变大 |
| 功率偏高 | 解离增强，自由基过饱和，成核概率上升 |
| 电极、腔壁、showerhead 沉积物 | 剥落直接产生颗粒；showerhead 孔半堵会改局部气流与电场 |
| arcing | 局部电场集中打火，产生碎屑 |
| PM 后未充分 seasoning | 初期成核与剥落都偏高，MON 容易在 PM 后早期报警 |

**与 RF 侧的耦合**：沉积物增厚会让腔体阻抗漂移 → matcher 位置先偏、反射后升高；局部电场集中 → arcing → 颗粒。所以「MON PA NG 反复 + matcher 位置逐周漂移」是同一条线索的两个末端，可以并案看。

**排查顺序**：清洁/seasoning 状态 → 压力与流量 → 电极与 showerhead 沉积 → matcher 位置趋势 → OES 是否显示气相成核迹象。

## 术语（本批 9 词）

| 词 | 一句话 |
|---|---|
| plasma | 部分电离气体，电子与离子密度近似相等，能导电并响应电磁场 |
| sheath | 电极前的正离子薄层，腔内电压主要降在这里，离子在此被加速 |
| matcher | 阻抗变换网络，把等离子体阻抗变换回 50Ω |
| tune | 串联可调电容，主要调电抗 |
| load | 并联可调电容，主要做电阻变换 |
| setpoint | 工艺设定的目标功率，不等于腔体实际吸收 |
| forward | 入射功率，电源端测得 |
| reflected | 反射功率，衡量腔体偏离 50Ω 的程度 |
| self-bias | 电极面积不对称产生的直流偏压，决定离子轰击能量 |

## 怎么用它

- 反射高：先按那句总结分「腔体侧 / 传输侧」，再决定查沉积物还是查线缆接地。
- 起辉失败：按「压力与极间距 → 电极表面状态 → power ramp → matcher preset」顺序查，帕邢定律解释为什么压力与间距影响最大。
- MON PA NG：直接用上面那条排查顺序，并同时看 matcher 位置趋势，判断是否同一根因。
- 讲给主管：反射功率高 ⇒ 有效耦合功率下降 ⇒ 沉积速率与均匀性受累；我机台上主要嫌疑是沉积物与低频模块可靠性，不是电源本身。
