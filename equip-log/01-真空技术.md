## 原笔记留存（2026-09-19）

- **①泵**：干泵（螺杆 / 爪式 / 涡旋）vs 油泵（旋片式）——干泵初始成本高但维护低、噪音低、洁净度高；油泵需定期换油、极限真空更低、噪音偏大、有油雾返流风险、抗杂抗水汽强。
- **②真空规量程**：皮拉尼（热传导率）粗–低真空 10⁵~10⁻¹；电离（离子流，受气体种类与污染影响）高–超高真空 10⁻¹~10⁻⁸；电容薄膜（绝对，压差膜片变形 + 电容变化）常压–较低真空精密控制。
  > 原记录只写了模糊量级，且皮拉尼下限偏低；按厂商规格修正后的准确量程见「展开」第 2 节。
- **③氦检**：逆扩散 + 分子泵对氦压缩比极低 + 磁偏转离子流确认漏率。
- **一句话**（挂靠 throttle）：类似蝶阀但口小精度高；控压不住的常见原因 = 阀芯运动受阻 / 密封面磨损泄露 / 节流口堵塞。

## 展开

### 1. 泵：干泵 vs 油泵 vs 加罗茨

**核心差异在压缩方式**：干泵靠螺杆 / 爪式 / 涡旋等结构挤压排气，排气通道**不用油密封**；油泵靠油膜的密封、润滑、冷却把气体压缩排出，代表是旋片式。

| 维度 | 干泵 | 油泵 |
|---|---|---|
| 洁净度 | 完全无油，零污染 | 有油雾返流风险 |
| 极限真空 | 约 0.5 Pa | 可达 10⁻³ Pa 级 |
| 初始成本 | 较高，约为油泵 2~3 倍 | 入门价低 |
| 维护 | 几乎免维护，无废油 | 需定期换油，年均耗油 ≈ 设备价 15% |
| 噪音 | 较低，平均低约 8 dB | 偏大 |
| 适用介质 | 洁净气体 | 抗杂质、抗水汽强 |

- **选干泵**：半导体镀膜 / 刻蚀 / 光刻（对碳氢污染零容忍）、医药食品、精密实验室。
- **选油泵**：7×24 连续烘干、大批量溶剂脱溶、抗过载强的粗真空场景。
- **选型顺序**：洁净度 → 真空度 → 介质特性 → 总拥有成本。

**加罗茨泵（Roots）**：罗茨泵**不能单独工作**，必须配前级泵。

- 作用区间是 10 kPa ~ 0.1 Pa，正好补前级泵在这一段抽速骤降的缺口。
- 干泵单机极限约 0.5 Pa；**干泵 + 罗茨**可到 10⁻² ~ 10⁻³ Pa。
- 只在「要更高真空 / 要更大抽速 / 要短抽气时间」时才加，粗真空场景单台干泵就够。

### 2. 真空规：三种的量程与选型

| 维度 | 电容薄膜 CDG | 皮拉尼 Pirani | 电离 Ionization |
|---|---|---|---|
| 原理 | 膜片受压变形 → 电容变化 | 热丝热损失 → 反映分子密度 | 电子电离气体 → 离子流 |
| 是否受气体种类影响 | **无关** | 强依赖，需按气体校准 | 中等依赖 |
| 量程 | 10⁻² ~ 10⁵ Pa（满量程常见 100 Torr / 1000 Torr） | 约 10⁻² ~ 10⁵ Pa（10⁻⁴ ~ 1000 mbar） | 约 10⁻¹⁰ Torr ~ 1 Pa |
| 精度 | 最高（重复性优于 0.1%） | 中等 | 较高 |
| 成本 | 较高 | 最低 | 中等 |

- **CDG 是绝对压力计**：直接测压力，全量程偏差 < 5.3%，低压区（10⁻² ~ 1.33×10² Pa）偏差 < 1.6%。控压回路的主反馈源就是它。
- **皮拉尼**：结构简单、无活动件、响应快；但极低压段灵敏度有限，且怕油蒸气、粉尘污染。
- **电离规**：唯一能测 10⁻⁷ Pa 以下的类型；B-A 规用细丝收集极把 X 射线光电流本底压到 4×10⁻¹⁰ Torr。**上限约 1 Pa（10⁻² mbar）**——热阴极在该压力以上会烧毁灯丝，所以必须先粗抽到 10⁻² mbar 以下再开规，不能曝大气。
- **选型**：粗低真空监测用皮拉尼；精密控压、气体种类会变或未知时用 CDG；高 / 超高真空用电离；宽量程用「皮拉尼 + 电离」复合规或分段组合。

### 3. 氦检：逆扩散 + 质谱

**为什么是逆扩散**：氦气从漏点逸出后，在压力梯度下**逆着分子泵的压缩方向**扩散进质谱室。分子泵对氦的压缩比只有 10~100 倍，等于给氦留了一条低阻抗通道——这就是逆扩散检漏法的设计基础。

**系统构成**：

| 部件 | 作用 |
|---|---|
| 机械前级泵 | 旋片式双级泵，抽速约 2 L/s；预抽 + 维持分子泵前级真空 |
| 涡轮分子泵 | 核心泵组，抽速 150 L/s 以上；把质谱室抽到 10⁻⁴ Pa 以下 |
| 组合阀 | 控制气流路径与真空切换 |
| 质谱室 | 离子源（电子轰击成 He⁺）→ 磁偏转按质荷比只放质量数 4 → 收集器测离子流 |

- 部分中高端机型用**双分子泵**：响应更快、本底更低、双泵交替可延长维护周期，多见于电池 / 压缩机产线的在线快节拍检测。
- **灵敏度**可达 10⁻¹² Pa·m³/s 量级，远优于气泡法、压降法。单位换算：**1 Pa·m³/s = 10 mbar·L/s**（欧洲常见写法是 mbar·L/s，INFICON 产品规格即用此单位）。

### 4. 节流阀（throttle）：机制、失效与蝶阀对比

> ⚠️ 网页资料混有液压节流阀语境（油液污染、油温粘度）。下表只保留与**真空侧节流 / 控压**相通的部分；液压专属项已剔除。

**机制**：靠缩小流道截面积提高流速、降低下游压力。半导体机台的 throttle 阀多在真空侧，以蝶阀 / 摆阀形式改变流导，靠伺服驱动跟上 MFC 流量变化。

**失效 = 节流口前后压差维持不住，或阀芯动不了**：

| 失效类型 | 表现 | 排查 |
|---|---|---|
| 阀芯卡滞 | 开度失控，压力不随指令变化 | 拆检阀芯表面有无划痕、拉毛、异物；清洗阀腔 |
| 密封面磨损 / 内漏 | 压力建不起来或维持不住 | 查阀芯与阀座接触面冲蚀痕迹；测配合间隙，超标就换 |
| 节流口堵塞 | 有效过流面积变小，流量偏低、压力异常 | 查节流口异物；清洁通道，必要时加滤网 |
| 负载 / 抽速波动 | 压差随下游变化而漂移 | 真空侧对应「泵抽速下降 / 管路积垢」，不是阀的问题 |
| 环境温度变化 | 机械尺寸与驱动特性漂移 | 查阀体与环境温度是否超出额定范围 |

**与蝶阀的区别**：

| 维度 | 节流阀 / throttle | 蝶阀 |
|---|---|---|
| 定位 | 精密调节 | 快速启闭、大通径截流 |
| 精度 | 高（±1% 级） | 低（粗略） |
| 口径 | 小（DN6~50） | 大（DN50~2000+） |
| 流阻 | 主动制造压降 | 全开时接近零阻力 |
| 注意 | 大流量时能耗高 | 半开时涡流、振动，不宜长期当调节件 |

两者不互斥：主路用蝶阀通断、支路用节流阀精调是常见组合。

## 盲区 / 待核对

**已核对（2026-11-01，口径统一到厂商 datasheet）**

- 皮拉尼量程：INFICON PSG010 为 8×10⁻⁴ ~ 1000 mbar、PGE300 为 1×10⁻⁴ ~ 1000 Torr（1.3×10⁻² ~ 133000 Pa），ULVAC SW100 为 5×10⁻² ~ 1×10⁵ Pa → 统一取 **10⁻² ~ 10⁵ Pa（10⁻⁴ ~ 1000 mbar）**。原记录「10⁻³ Pa」下限偏低约一个量级，属抄写误差。
- 电离规上限：热阴极在高于 **10⁻² mbar** 时灯丝会烧毁（Teledyne Hastings、MKS 资料一致），故上限约 1 Pa，不能曝大气。
- 氦检漏率单位：**1 Pa·m³/s = 10 mbar·L/s**，两种写法可互换核对。
