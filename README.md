## 4. ⚡ 日常只用对话，文件负责记住

**排期基准：2026-09-06（周日）= Day 0；2026-09-07（周一）= Day 1。**
原计划保留 14 周，共 98 个执行日；第 90 天验收成果，最后一周收尾。原来的“30 / 60 / 90 天”日期偏差已校准。
实际完成数以文件为准，不把这份 README 当滚动状态账。

### 你每天可以直接这样说

- **“今天需要做什么？”** → agent 读取日期、计划、勾选状态与夜班安排，给一个优先动作和少量顺带动作。
- **“Tiny+ 已经在 Studio One 响了，帮我勾上。”** → 对应 `1-0`，写回 JSON，并同步总览与 HTML。
- **“前四小节扒完了，但还没导出。”** → 只记进展备注，不把“8 小节 MIDI 已导出”整项误勾。
- **“我做了 25 分钟，帮我打卡。”** → 按实际日期记一次；不重复累计。
- **“这几天夜班 / 太累了。”** → agent 确认日期后记豁免 / 低能模式，不把暂停当作完成。
- **“新增一条故障：现象是……，排查经过……，根因还不确定。”** → 按你提供的内容落盘；不替你编造根因。
- **“《Lemon》1:23 鼓停半拍再进副歌，记一条” / “术语表到 10 词了”** → 记入积累项（计数与提醒在每日报告里；`AGENTS.md` §8.2）。

**你不用自己运行脚本，也不用每天打开网页操作。** 想看全貌时再打开进度总览或 HTML。
新 agent 拿到**这份最新项目目录并具有读写权限**，先读 `AGENTS.md` 后即可接管文件工作流；脚本运行需 Python 3.11+。
在 Arena 可直接下载整个工作区保留自己的完整副本，**不再额外生成 ZIP**；下载不是自动同步到 Windows，也不是公开发布。

### 文件在哪里，分别干什么

| 内容 | 唯一记录文件 | 平时想查看时打开 |
|---|---|---|
| 排期 / 勾选 / 备注 / 证据 / 打卡 | `progress/plan90.json` | `progress/进度总览.md` / `tools/90天进度表.html` |
| 真实故障 / 排查 / 处理 / 预防 | `data/faults.local.json` | `data/故障模式库.local.md` / `tools/故障模式库.local.html` |

JSON 改完，agent 自动生成其余视图。**Markdown / HTML 快照不是第二份要手工维护的进度。**
网页默认只读，即使预览环境不允许缓存，也能看完整的已同步内容；不会拿旧浏览器缓存盖掉文件。
想手动改时，可在 Chrome / Edge **连接项目 JSON**；不支持直接写文件的浏览器可临时编辑并导出交 agent 合并。
如果旧浏览器里另有记录而未包含在项目文件中，只需一次性导出 JSON 交 agent 合并；不能从 HTML 文件本身恢复未导出的旧缓存。
详情 → [`manuals/AI与工具手册.md`](manuals/AI与工具手册.md) §4.6。

> **“本地”的边界**：这里指当前项目工作目录，不会自动同步到另一台电脑。Arena 中修改的是本工作区；换电脑 / 换 agent 时须带上最新文件。
> `*.local.*` 只防误提交 Git，**不是加密，也不是“云端不可见”**。企业不允许出厂的原始日志，应只交给获准的本机 agent；云端对话只提供允许分享的脱敏摘要。

## 5. ⛔ 硬性约束速查

> 完整版见 [`01-个人档案.md`](01-个人档案.md) §9

| 类别 | 约束 |
|---|---|
| 时间 | 按每周有效 **8–10 小时**设计，不要按 20 小时 |
| 夜班 | W5 / W10 是浮动缓冲，不代表已确认夜班；实际夜班日期另行确认 |
| 保密 | 故障分享须脱敏候选稿、人工复核与厂规许可；不是点一次导出就能公开 |
| 混音 | 时间 ≤ 总工时 20%；只准用 4 个手法 |
| 工具 | 任何工具**配置超过 2 小时就放弃**，换最笨的方案 |
| 乐理 | **不许系统学教材**，只在扒带遇到困难时按需查 |
| 音韵学 | **W9 之前不许碰**（王力 / 唐作藩）；Praat 实验每月 ≤ 1 次、30 分钟封顶 |
| IPA | 甜点不是主菜 —— **音乐线落后就停它** |
| 完成定义 | 一首歌 = 工程文件 + 导出音频 + **公开发布链接** + ≥100 字复盘 |
