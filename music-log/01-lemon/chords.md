### 判定记法（怎么填这一格）
- **`半`列**：4/4 拍里 `前` = 第 1–2 拍，`后` = 第 3–4 拍；**bass 音头落在哪半，和弦多半从哪半换**（卡点表 §2.11：和弦变化点多在 kick / snare 上）
- **旋律关键音**：只开人声轨、降速 50%，每半小节记**强拍音 / 长音 / 句尾音**（最可能是和弦内音）
- **定性质**：根音上方**大三度 → 大三和弦**（如 `G + B → G`）；**小三度 → 小三和弦**（如 `E + G → Em`）
- **旋律音在根音下方**：先把旋律音**移高/低八度挪到根音附近**再比三度（转位思维），还是比不出就标 `?`
- **每小节只有一个 bass 音时**（如 5–8）：前半的根音多半沿用后半的，但**先听后写**，不默认
- **根音存疑**（如 5–8 的 F 不在调内）：根音列写 `F?`。bass 音不一定是根音（可能是三音 / 五音，或本身就是调外和弦），拿不准就标 `?`，不猜
- **听不出三音**：和弦列写 `根音?`，不猜
