## 和声 vs bass 走线的听辨核对（6-2 · 2026-10-16 听辨）
- 主歌里「低音线」与「上层和声」哪里一致、哪里不一致：
  - **13–20**：只有 人声 / 鼓 / bass，**无上层可比**；能确认的是**人声主音落在 6（B）/ 1（D）/ 3（F♯）**上，**未能确认上层是否落在 `B→F→E` 和弦内** `?`
  - **20 小节后 2 拍**：bass = **3（F♯）**（非 2/E）；钢琴、吉他**与 bass 完全一致**
  - **21–28**：钢琴**只有单音**、与 bass 完全一样；吉他听起来就是 **B / F / E 的和弦**（听不真切）。Melodyne 分析：B 的和弦**缺 3 音**，只见**根音 + 5 音** `?`
- 暂结论：主歌段**未发现 bass 与上层和声错位**——上层基本跟随低音线（**2026-10-20 对账确认**：源在此段记 5 和弦 `B5/F5/E5`，与"只见根音 + 5 音"一致；详见下节）

## 对账（2026-10-20 逐段比对；来源已整理，本节为结论）

    - 29-34小节 **A♯5-B5** 循环（一个2拍）

- 比对范围：本期只比 **13–55（一段主歌 + 副歌）**；intro / 间奏 / verse2 及以后不填

- **对上了**：
  - verse1 根音走线 `B5–F5–E5`（2 拍–2 拍–4 拍）、20 小节后半 `F♯5`

- **对不上的原因（一条结论）**：主歌与 29–34 的源统一写 **5 和弦**（强力和弦），不含决定大小的三度；我用「人声旋律关键音 → 三度」反推 `Bm / F6 / A♯m`，会推过头 —— 与 `6-2` 记录的「上层 Melodyne 只见根音 + 5 音、缺 3 音」一致。**副歌相反**：上层真有完整三和弦与 `D6`，我的三度推断基本成立。

- **待复听**：
  - 45 后半：`A♯` vs 源 `F♯`（先听这一格）
  - 我多写的六 / 七音（`F6 / Bm7 / D7 / C♯dim7 / C♯m7`）是否真在编曲里 —— 副歌确有 `D6`，六音不排除来自人声层；主歌按源只有 5 和弦
