## 每首歌里面的文件

| 文件 | 内容 | 是否入库 |
|---|---|:---:|
| `original/` | 原曲音频 | ⛔ **否**（版权） |
| `stems/` | Moises 分轨出的 4 条干轨 | ⛔ **否**（版权） |
| `melody.mid` | Step 1 产出 · 主旋律 | ⚠️ 默认否，可 `git add -f` |
| `chords.md` | Step 2 产出 · 和声进行 + 第几小节 + **对账结果与你的盲区** | ✅ |
| `structure.md` | Step 3 产出 · 时间戳 + 方块图 | ✅ |
| `project.song` | Studio One 工程 | ⛔ 否（二进制） |
| `export.mp3` | 最终导出 | ⛔ **否**（版权 + 体积） |
| `notes.md` | Step 6 产出 · ≥100 字复盘 | ✅ |

**结论：仓库里真正留下来的只有三个 `.md`** —— 那才是学习本身。
音频和工程文件留在本地，它们只是过程。

> ⚠️ **对账顺序**：先自己扒完，**最后**才去 Hooktheory / U-FRET 查答案。
> 先查答案再扒 = 抄作业，等于没练。
